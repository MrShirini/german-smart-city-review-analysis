# Smart City Review Mining

## Overview

This project analyzes public app store reviews of the German municipal application **Mängelmelder**.

Using text mining, sentiment analysis, and topic modeling, the project investigates:

* What citizens value
* What frustrates citizens
* Which features drive engagement

The goal is to extract actionable priorities that can support future Smart City service development in **Ilmenau** and guide the **SensBee** feature roadmap.

---

## Research Topic

Analyze public app store reviews of existing smart city and municipal applications from German cities (e.g., Mängelmelder).

Apply text mining and sentiment analysis to:

* Identify what citizens value
* Identify what frustrates citizens
* Identify which features drive engagement

---

## Dataset

* Mängelmelder App Store Reviews

## Findings

### What Citizens Value

#### Fast Response

**Keywords**

* schnell (fast)
* melden (report)
* erledigt (resolved)
* mängel (issues)
* reagiert (responded)

Citizens value quick issue reporting and fast municipal response times.

#### Reliability

**Keywords**

* funktioniert (works)
* top (excellent)
* einwandfrei (flawless)
* mängel (issues)
* klasse (great)

Users appreciate reliable functionality and stable application performance.

#### Issue Resolution

**Keywords**

* mängel (issues)
* meldungen (reports)
* bearbeitet (processed)
* behoben (fixed)
* schnell (fast)

Citizens are satisfied when reported issues are processed and resolved quickly.

#### Usability

**Keywords**

* gute (good)
* einfache (simple)
* meldung (report)
* idee (idea)
* bedienung (usability)

Users value a simple and intuitive application design.

---

### What Frustrates Citizens

#### Update and Display Problems

**Keywords**

* meldungen (reports)
* seit (since)
* update (update)
* angezeigt (displayed)
* melden (report)

Users report problems related to updates and incorrect display behavior.

#### GPS and Functionality Issues

**Keywords**

* meldung (report)
* funktioniert (works)
* schade (unfortunate)
* gar (completely)
* gps (GPS/location service)

Citizens are frustrated by malfunctioning features and GPS-related issues that affect reporting accuracy.

#### Categorization Problems

**Keywords**

* mängel (issues)
* kategorie (category)
* gemeldet (reported)
* möglich (possible)
* gute (good)

Users experience difficulties with issue categorization and report classification.

#### Crashes and Instability

**Keywords**

* ab (down/off)
* stürzt (crashes)
* idee (idea)
* mängel (issues)
* sterne (ratings)

Recurring crashes and technical instability negatively impact the user experience.

---

## Features Driving Citizen Engagement

The analysis indicates that citizen engagement is primarily driven by features related to:

* Issue reporting
* Response time
* Notifications
* Tracking
* Application performance

These categories received the highest number of mentions across both positive and negative reviews, suggesting that they strongly influence citizen interaction with municipal applications.

The findings highlight the importance of:

* Efficient problem reporting
* Transparent communication
* Status tracking
* Reliable performance
* Fast municipal responses

---

## Recommendations for Ilmenau and SensBee

Based on the review analysis, future Smart City services should prioritize:

* Fast issue reporting workflows
* Quick response and resolution processes
* Reliable and stable application performance
* Accurate GPS functionality
* Improved issue categorization
* Transparent status tracking
* Effective notification systems
* Simple and intuitive user interfaces

These priorities can help improve citizen satisfaction, engagement, and trust in digital municipal services.
